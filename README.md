# 游戏内R树空间索引系统

## 项目描述

游戏内R树空间索引系统的bug修复项目。核心模块 `spatial/rtree.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- R树构建完全没做范围查询是O(n)
- 插入完全没做不能插入矩形
- 删除完全没做不能删除矩形
- 范围查询完全没做不能快速查询范围内的矩形
- R树质量完全没做不能评估R树质量
